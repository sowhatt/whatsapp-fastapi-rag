## Différence avec le Shop embarqué dans Online

Les routes historiques **dans ce dépôt Online** utilisent encore des écritures `Product.stock` et le Core local manipule ses réservations dans la même session. Le worktree parent utilise déjà `ShopInventory` et le contexte boutique. C'est pourquoi l'audit parent ne peut pas être remplacé par une recherche dans Online seul. Aucun de ces deux chemins réels n'est branché sur le laboratoire.

Recherche : affectations `.stock`, constructeurs `Product`/`ShopInventory`, `adjust_stock`, `set_shop_stock`, `set_initial_shop_stock`, `setattr`, SQL produits/inventaires, hooks SQLAlchemy, parcours ventes/achats/imports et synchronisation. Les éventuels writers manuels, scripts hors périmètre et versions distantes restent inconnus. Ce manque de preuve interdit une bascule réelle.
